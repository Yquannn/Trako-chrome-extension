# Publish this privacy policy on GitHub Pages

1. Confirm the support email in `docs/index.html` is correct: `dondonbautista1223@gmail.com`.
2. Commit and push `docs/` to the `main` branch of `Yquannn/Trako-chrome-extension`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/docs**, then select **Save**.
6. Wait for GitHub's Pages deployment to complete and open the published page.
7. Paste the published URL into the Chrome Web Store's **Privacy policy URL** field.

Expected URL after a successful deployment:
https://yquannn.github.io/Trako-chrome-extension/

The URL is not confirmed live until deployment succeeds. This folder contains the page and its local mascot asset; it has no external scripts, fonts, analytics, or build dependencies.
