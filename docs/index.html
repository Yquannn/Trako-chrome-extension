Trako Order Exporter
Local order history export

Privacy Policy

Last updated: October 22, 2026

Your order information is processed in your browser. Trako Order Exporter does not send extracted order information to Trako servers.

Overview

Trako Order Exporter helps users export accessible online shopping order information into CSV files for personal record-keeping.

Information we access

The extension reads rendered page content on supported shopping websites to identify order history and extract available order details. These may include:

  • Platform and seller names, order IDs, and product image URLs.
  • Product names, variations, quantities, prices, order totals, and currency.
  • Purchase and delivery dates, order and delivery statuses, and tracking numbers.

The extension does not ask for passwords or collect cookies or authentication tokens.

How information is used

Order information is used only to scan orders, display export progress and skipped-item reasons, and generate CSV files requested by the user.

During an export, the extension may temporarily open order-detail pages on the shopping website using the user's existing browser session.

Local processing, storage, and sharing

Order information is processed locally in the user's browser. The extension does not send extracted order information to Trako servers or third-party analytics or advertising services.

The extension does not sell or share order information with the developer or other parties.

Scan results are held temporarily in browser memory. The extension does not maintain a separate persistent database of order history.

Shopping websites continue to handle normal page requests under their own privacy policies.

Downloads and deletion

When the user initiates an export, the extension creates a CSV download. Exported files remain wherever the user saves them until the user deletes them.

Users can delete exported files using their device's file manager. Uninstalling the extension does not delete previously downloaded CSV files.

Data security

Exported CSV files may contain personal purchase information. Users should store these files securely and share them only with trusted recipients.

Changes

This policy may be updated when the extension's functionality or data practices change.
